# 移植与适配指南

这个 skill 是一套**可交接的方法**，不是绑在某个 AI、某台机器上的脚本集合。别人拿它配合自己的 AI 做同一件事，读完这份就够开工。

## 一、先分清三类内容

文档里混着三类信息，搬走时处理方式不同：

| 类型 | 例子 | 换环境后 |
|---|---|---|
| **通用规则** | 各步骤依赖和并行条件、每步验收证据、模板命名 `MMDD-英文名`、卖点照录原文、完整装修默认由 agent 绑定 | 按本轮执行 |
| **平台事实** | 1688 mtop 接口与签名、SHOPLINE 主题 CLI 命令、采集站与 Phalanx 的接口字段 | 有账号就能用，通常不变；平台改版才需更新 |
| **本机实测** | 具体店铺域名、主题 ID、商品 ID、代理端口、崩溃日志 | 只当参考案例，**不要照抄**，以你自己环境跑出来的为准 |

第 5 步的接口细节、第 7 步的 CLI 排障、第 8 步的字段定位属于第二类，是这份 skill 最值钱的部分；第三类只用来判断「你遇到的这个现象别人也遇到过没有」。

## 二、需要具备的能力

| 能力 | 用途 | 没有时的替代 |
|---|---|---|
| 执行 shell 命令 | 跑脚本、调 CLI、比对文件 | 无替代，必须有 |
| 读写本地文件 | 素材落盘、模板 JSON、说明文件 | 无替代，必须有 |
| 一个带 CDP 的 Chromium | 第 1、5、6、9 步；抓接口、读登录态、上传本地文件 | 用你已有的浏览器加 `--remote-debugging-port=9222`；或用 Playwright 自带 Chromium（本 skill 的 `agent_browser.py` 就是这条路） |
| Python 3.9+ 与 playwright | 跑 `scripts/` 下四个 Python 脚本 | 手工照接口文档发请求（第 5 步给了完整参数） |
| Ruby 2.6+ | 第 1 步落盘脚本 `save_product_page.rb` | macOS 自带；Linux `apt install ruby`；Windows 用 RubyInstaller 或 WSL。缺 ruby 时按 [采集附册](01a-商品页采集与落盘.md)的结构手工建目录、下载媒体、生成两份文档，**验收标准不变** |
| 账号：采集站、Phalanx、SHOPLINE、1688 | 第 2–9 步 | 缺某项时暂停依赖该账号的步骤。独立分支可继续，待验收步骤保留实际状态。 |
| 能连境外后台的网络 | SHOPLINE 后台、OAuth | 需要代理；国内站直连 |

**AI 助手只要能做前三条，就能跑完整流程。** 判断方法：让它执行 `python3 scripts/check_env.py`，能跑通并读懂输出就够了。

### 外部依赖（不在本 skill 包内）

| 依赖 | 用在哪 | 没有怎么办 |
|---|---|---|
| `api/*.md` 接口文档（采集站、Phalanx） | 第 2–4 步 | 向团队索取；或按第 5、7 步的实测记录反推端点与字段 |
| SHOPLINE CLI（`@shoplineos/cli`） | 第 7–8 步上传模板 | 无等价替代。要么装 CLI，要么在后台界面手工改主题（工作量大、易漏） |
| 采集站 / Phalanx 账号 | 第 2–4 步 | 必须向店铺方要，无法绕过 |

第 1 步的采集**已经内置**，不再需要额外的采集 skill：提取脚本在 `assets/`，落盘脚本是 `scripts/save_product_page.rb`，方法论和踩坑表在 [商品页采集与落盘](01a-商品页采集与落盘.md)。

## 三、可配置项：改环境变量，不改代码

| 变量 | 默认 | 影响 | 什么时候改 |
|---|---|---|---|
| `AGENT_BROWSER_PROFILE` | macOS/Linux `~/.cache/agent-browser`；Windows `%LOCALAPPDATA%\agent-browser` | 浏览器登录态存放目录 | 想换盘、多人共用一台机、要隔离身份时 |
| `AGENT_BROWSER_PORT` | `9223` | CDP 端口 | 端口被占，或同时要两个实例（必须配不同 profile） |
| `AGENT_BROWSER_HOST` | `127.0.0.1` | CDP 主机 | 浏览器跑在另一台机器或容器里时 |
| `SHOPLINE_CLI` | 自动找 `sl` / `sl.cmd` / `~/.shopline-cli/...` | 第 7–8 步的 CLI 路径 | CLI 不在 PATH 里 |
| `DLZ123_PHPSESSID` | 空 | 采集站会话，跳过登录 | 不想每次登录，想直接注入会话 |
| `HTTPS_PROXY` / `ALL_PROXY` | 空 | 访问境外后台 | 需要代理时 |

```bash
# macOS / Linux
export AGENT_BROWSER_PROFILE="$HOME/.cache/agent-browser"
export AGENT_BROWSER_PORT=9223
export SHOPLINE_CLI="$HOME/.shopline-cli/node_modules/.bin/sl"
```

```powershell
# Windows PowerShell
$env:AGENT_BROWSER_PROFILE = "$env:LOCALAPPDATA\agent-browser"
$env:AGENT_BROWSER_PORT = "9223"
$env:SHOPLINE_CLI = "C:\Users\你\AppData\Roaming\npm\sl.cmd"
```

脚本只读环境变量和命令行参数，没有任何一处写死用户名或机器路径。

## 四、目录约定

```
<工作区>/
├── skill/product-decoration/        # 本 skill（放哪都行，见下）
│   ├── SKILL.md
│   ├── references/                  # 10 步文档 + 附册 + 总览
│   ├── scripts/                     # agent_browser / 1688_image_search / fill_shopline_template / save_product_page / check_env
│   └── assets/                      # 采集提取脚本与标签 HTML 模板（必须与 scripts/ 同级）
├── api/                             # 平台接口文档 + 模板本地副本
│   └── themes/shopline/templates/<店铺>/product.<模板名>.json
└── 商品数据/
    ├── _work/                       # 采集清单、临时清单
    └── MMDD-中文-英文/               # 单品素材目录
        ├── 轮播图/ 详情图/ 封面.jpg
        ├── 商品名称_简介_标签.md
        ├── 单品采集结果.csv
        ├── 1688搜图结果.json/.csv
        └── 商品装修说明.md
```

- 文档里的相对链接默认 skill 在 `<工作区>/skill/product-decoration`。放在别处时，只需改 `SKILL.md` 和各步文档里的相对路径，流程不受影响。
- `scripts/` 与 `assets/` 的**同级关系不能动**。`save_product_page.rb` 用 `../assets/product-feature-tags.html` 定位标签模板，单独搬走任一个都会报错。
- `商品数据/` 与 `api/` 首次跑会自动建；`api/` 里的接口文档需要你从自己团队拿到，**没有就按第 5、7 步的实测记录重建**。
- 素材目录、模板名的命名规则是通用规则，别改，改名会让跨步骤核对失效。

## 五、平台差异

| 项 | macOS | Windows | Linux |
|---|---|---|---|
| 浏览器启动 | `python3 scripts/agent_browser.py` | 同（`python` 或 `py`） | 同；无桌面环境时加 `xvfb-run` |
| profile 默认位置 | `~/.cache/agent-browser` | `%LOCALAPPDATA%\agent-browser` | `~/.cache/agent-browser` |
| 逐字节比对 | `cmp a b` | `fc /b a b`，或 `python -c "import sys;a,b=[open(x,'rb').read() for x in sys.argv[1:]];print(a==b)" a b` | `cmp a b` |
| 临时目录 | `mktemp -d` | `[IO.Path]::GetTempPath()` | `mktemp -d` |
| CLI 可执行 | `sl` 或 `~/.shopline-cli/node_modules/.bin/sl` | `sl.cmd`（npm 全局目录） | `sl` |
| 系统 Chrome 加调试端口 | **只有 macOS 26/27 有 `libaperitif` 拦截**，命令行启动会在导航时被杀；其他 macOS 版本可试 | 直接 `chrome.exe --remote-debugging-port=9222` | 直接带参数启动即可 |
| 中文路径 | 无问题 | 无问题，但命令行注意引号 | 确认 locale 为 UTF-8 |

**唯一一条「只在 macOS 成立」的结论**就是上面那条 Aperitif 拦截。别的系统看到「命令行 Chrome 崩了」不要套这个解释，先看崩溃日志。

## 六、AI 助手差异

| 助手能力 | 能做什么 | 要注意 |
|---|---|---|
| 能跑命令 + 能读写文件 + 能连 CDP | 全流程都能做（推荐） | 让它在动手前先跑 `check_env.py` |
| 有浏览器工具但只有导航/点击/截图，没有执行 JS 和 Network | 第 6 步能做；第 1 步退化成逐页点开手抄，第 5 步退化成 UI 兜底 | 第 1 步拿不到 `manifest`，轮播和详情顺序难保证，容易漏采；第 5 步拿不到 `imageId` 和签名参数 |
| 只能点击 GUI | 第 6、9 步能勉强做 | 第 1 步无法一次提取全部结构化数据；第 2–5、7–8 步做不了，需要人代跑命令 |
| 无浏览器，只有 HTTP | 第 3、4 步能做 | 第 1、5、6、9 步缺证据链 |

判断标准只有一句：**能不能拿到 CDP**。拿到就能抓接口、读 cookie、塞本地文件；拿不到就只能在页面上点。

WorkBuddy 的内置浏览器属于第二类（有导航、截图、CUA 点击、DOM 快照，无 JS 执行与 Network 监听），所以本 skill 默认用 `agent_browser.py`，只在用户明确要求时才切内置浏览器。

## 七、新环境落地

1. 把 skill 放到 `<工作区>/skill/product-decoration`（`scripts/` 与 `assets/` 一起放，别拆开）
2. `python3 scripts/check_env.py --workspace <工作区>`，按输出补齐（阻塞项通常是 playwright、Chromium 内核、ruby 或 `assets/` 缺失）
3. `python3 scripts/agent_browser.py` 起浏览器，在弹出的窗口里登录要用的站点（1688、店铺后台）
4. 准备凭证文件，见下一节
5. 跑最小闭环：`python3 scripts/1688_image_search.py --img <任意商品图> --out /tmp/t`，能出候选就说明第 5 步通了
6. `sl theme list`，确认第一行域名是本轮店铺、不报 400
7. 用一款真实商品跑第 1–2 步：先 `ruby scripts/save_product_page.rb --help` 确认 ruby 和脚本路径都对，再采集落盘，验收素材和 CSV
8. 再进第 3 步，按流程往下

第 5 步能跑通，说明浏览器、playwright、cookie、签名、网络五样都对了，是最划算的先验动作。

## 八、凭证怎么放

| 凭证 | 推荐位置 | 环境变量替代 | 说明 |
|---|---|---|---|
| 采集站账号密码 | skill 根目录 `独立站产品刊登系统key.rtf`（或 `.txt`/`.json`） | `DLZ123_ACCOUNT` / `DLZ123_PASSWORD` | 明文文件，**不要提交到 git** |
| 采集站会话 | 不落盘，运行时注入 | `DLZ123_PHPSESSID` | 最省事，失效重登 |
| Phalanx 账号密码 | skill 根目录 `ally.rtf` | `PHALANX_ACCOUNT` / `PHALANX_PASSWORD` | 同一账号即 `ally.easyambass.com` 登录 |
| SHOPLINE | CLI OAuth，落在 `~/.config/configstore/shopline.json` | 无 | 不写进任何文档 |
| 1688 / 店铺后台 | 浏览器 profile | 无 | 手工登录一次即可长期复用 |

规则：文档只写位置不写值；值不进交付文件、不进终端回显、不进对话。

## 十、不要照抄的东西

- 具体店铺域名、主题 ID、商品 ID —— 你环境里的一定不同
- 代理端口（本文档里出现的 `1082`、`61989` 都是某次实测值）
- macOS 的 `libaperitif` 崩溃结论 —— 只在 macOS 26/27 成立
- profile 绝对路径、`/Users/<某人>/...` 这类路径
- 任何 `.rtf` 里的账号密码 —— 换成你自己的
