# 第五步 · 在 1688 以图搜同款

目标：用一张商品原图在 1688 找到同款货源，产出**可复核的候选清单**（标题、价格、销量、店铺地区、offerId 链接），供后续比价和选源。此步不改动店铺，只做搜索与记录。

至少一个本轮目标站点通过第 4 步验收后，按商品启动搜图，可与第 6 步并行。同款多店共用搜图结果。

从当前商品目录选主体清楚的商品原图，优先白底、能看清轮廓和关键结构。

## 为什么走接口

1688 的以图搜款页（`s.1688.com/youyuan/index.htm?tab=imageSearch`）直接打开会命中阿里 x5sec 反爬（`_____tmd_____/punish` 滑块页），而且验证状态**跟标签页绑定**，新开标签重放又会触发。点 UI 还依赖一串易变的哈希类名。所以主路径走 mtop 接口，UI 只作兜底。

## 前置：agent 浏览器里已登录 1688

接口要 cookie，签名要 `_m_h5_tk`，都得从一个真登录过的浏览器取。用**全流程共用的 agent 浏览器**（profile `~/.cache/agent-browser`，CDP 9223），不要另起实例，也不要用系统 Chrome。

```bash
python3 scripts/agent_browser.py --url https://www.1688.com/   # 已在跑就跳过
python3 scripts/agent_browser.py --status                      # 确认实例和标签页
```

窗口里登录一次 1688，登录态就留在 profile 里，后续任务不用再登。`scripts/1688_login_browser.py` 是等价的兼容入口（固定打开 1688）。

**macOS 26/27 专属结论**：不要试图从系统 Chrome 命令行启动——`libaperitif.dylib` 会把命令行启动的 Chrome 直接掐掉（`SIGTRAP`，helper 侧 `AperitifCheckInitialized` abort），表现是「能连上 CDP，一导航就整个进程消失」，与沙箱无关。Windows、Linux 和其他 macOS 版本没有这条限制，可以直接用系统 Chrome 加 `--remote-debugging-port`，见[移植与适配指南](移植与适配指南.md)第五节。

指纹伪装是必需的：裸 Playwright 的 `navigator.webdriver=true`、`plugins=0`、没有 `window.chrome`，x5sec 直接判机器，滑块怎么拖都返回 `验证失败(errorYpbxq)`。伪装项：`webdriver` 置 `undefined`、5 个 PDF 插件、`zh-CN` 语言链、`Apple Inc. / Apple M1 Pro` 的 WebGL 参数、`hardwareConcurrency`/`deviceMemory`、`window.chrome` 补齐、`--disable-blink-features=AutomationControlled`。指纹参数落盘固定，避免每次会话跳变（跳变本身是特征）。

依赖：`python3 -m pip install playwright && python3 -m playwright install chromium`。

## 主路径：一条命令

```bash
python3 scripts/1688_image_search.py \
  --img "<素材目录>/轮播图/10.jpg" \
  --out "<素材目录>"
```

脚本依次做：从调试浏览器读 cookie 与 `_m_h5_tk` → 图片 base64 上传拿 `imageId` → 等索引完成后查同款 → 落盘 `1688搜图结果.json` + `1688搜图结果.csv`，终端打印前 N 条。

`--top` 控制终端展示条数（默认 20），`--wait` 控制上传后等待秒数（默认 6），`--cdp` 换端口。

## 接口细节（排障与复现用）

**一个接口同时承担上传和搜索**：

```
POST https://h5api.m.1688.com/h5/mtop.relationrecommend.wirelessrecommend.recommend/2.0/
  ?jsv=2.7.2&appKey=12574478&t=<毫秒时间戳>&sign=<md5签名>
  &api=mtop.relationrecommend.wirelessrecommend.recommend&v=2.0
  &type=originaljson&dataType=json&timeout=20000
body: data=<urlencode 后的 JSON>
```

`data` 结构固定两层：

```json
{"appId": 32517, "params": "<stringify 后的业务参数>"}
```

**签名**：`sign = md5(token + "&" + t + "&" + appKey + "&" + data)`，`token` 是 cookie `_m_h5_tk` 按 `_` 切分的第一段，`data` 是请求体里那个字符串（未 urlencode 的原文）。

**上传图片**（拿 `imageId`）：

```json
{
  "beginPage": 1, "pageSize": 60,
  "searchScene": "pcImageSearch",
  "method": "uploadBase64WithRequest",
  "appName": "pctusou",
  "imageBase64": "<jpeg 的 base64>"
}
```

返回 `data.data.imageId`。

**查同款**：

```json
{
  "beginPage": 1, "pageSize": 60,
  "method": "getImageSearchPreResult",
  "searchScene": "pcImageSearch",
  "appName": "pctusou",
  "tab": "imageSearch",
  "imageId": "<上一步的 imageId>"
}
```

**关键坑：上传后必须等 5 秒以上再查。** 立刻查会返回 `ret=SUCCESS` 但 `data.data` 为空，看着像参数错，实际是索引没建好。脚本默认等 6 秒。

**响应结构**：货源在 `data.data.OFFER`：

| 字段 | 含义 |
|---|---|
| `found` | 命中总数（实测 700 量级） |
| `items[]` | 本页货源，商品字段在 `items[i].data` 里 |
| `items[i].data.title` | 标题 |
| `items[i].data.offerId` | 商品 ID，可拼 `https://detail.1688.com/offer/<offerId>.html` |
| `items[i].data.priceInfo.price` | 起批价（字符串） |
| `items[i].data.saleQuantity` / `bookedCount` | 销量 / 成交数 |
| `items[i].data.province` / `city` | 店铺所在地 |
| `imageAddress` | 上传图被 1688 转存后的 URL |
| `imageSessionId` | 图片会话标识，含裁切框与哈希 |
| `yoloCropRegion` | 主体识别框 `x1,y1,x2,y2` |
| `aiTabs` | 识图标签，通常 `严格同款`、`找相似` 加两三个中文关键词 |

`aiTabs` 里的中文关键词对第 7 步取英文商品关键词有参考价值，记进说明文件。

## 兜底：走 UI

接口不可用（登录态失效、接口改版）时用 UI，但必须**从首页入口走**，不能直接构造结果页 URL：

1. 打开 `https://www.1688.com/`
2. 点搜索框右侧「以图搜款」，选择器 `.imageSearchBtn--rzEnsrPn`（类名带哈希会变，按文本「以图搜款」兜底）
3. 首页本来就有一个 `input[type=file]`（accept `jpg/jpeg/png/bmp/webp`），可直接 `set_input_files` 塞本地图片，不必点系统文件框
4. 面板出现图片预览后，点面板内的橙色搜索按钮 `button.actionPrimary--sz2L3jNq`。**页面上至少有两个「搜索」**，顶部导航那个不是它，点错会把面板关掉
5. 会新开标签到 `air.1688.com/kapp/1688-search/pc-image-search/?tab=imageSearch&imageId=<id>`，结果由 iframe 渲染。URL 里的 `imageId` 可抄给接口法复用

## 反爬陷阱

| 现象 | 原因 | 处理 |
|---|---|---|
| 标题「验证码拦截」，URL 含 `_____tmd_____/punish` | x5sec 风控 | 用带指纹伪装的实例，从首页入口走；滑块不要用脚本硬拖（`drag` 会被当成页面平移，机器轨迹返回 `errorYpbxq`），交给人手动拖一次 |
| 新标签页又弹验证 | 验证状态与标签绑定 | 同一标签内导航，或回首页重新走入口 |
| 浏览器连上 CDP 但一导航就退出 | macOS Aperitif 拦截命令行启动的 Chrome | 改用 `scripts/agent_browser.py`（Playwright Chromium，不受拦截） |
| 滑块拖不动 | 裸 Playwright 特征暴露 | 用启动器的指纹伪装版本 |
| 返回 SUCCESS 但结果为空 | 索引延迟 | 上传后等 5~8 秒再查 |

## 记录与验收

完成后在 `商品装修说明.md` 记：

- 所用图片（相对路径）
- `imageId` 与结果页 URL
- 结果文件 `1688搜图结果.json` / `.csv`
- 命中总数与前几条候选（标题、价格、offerId 或链接）
- 第 5 步状态与完成日期（`YYYY-MM-DD`）

两份结果文件存在，`found > 0`、`items` 非空，候选与图片主体一致时，记录搜图已验收。货源选择是第 5a 步的前置，交用户确认候选后再录入采购和 ERP 数据。起批价、重量或规格需用所选货源对应的信息核对。

遇到站点拦截且无法自动绕过时，记录具体原因、已选图片和已尝试方式，留待用户手动搜图并提供结果，不要假装完成。
