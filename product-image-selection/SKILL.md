# 选图

交付一组尺寸、数量和来源可核对的商品图片。用户只说「选图」时，使用当前对话或工作区已明确的商品执行完整流程。用户指定范围、比例、张数、名称或只做某一步时，以本次要求为准。

| 默认宽高比（宽:高） | 张数 | 常用补图尺寸（像素，可按素材调整） |
| --- | ---: | --- |
| 16:9 | 3 | 1920 × 1080 |
| 4:3 | 2 | 1440 × 1080 |
| 1:1 | 2 | 1080 × 1080 |
| 9:16 | 2 | 1080 × 1920 |
| 3:4 | 2 | 1080 × 1440 |
| **合计** | **11** | |

## 1. 确定商品与素材

1. 用户给商品名、简称或目录时，先查当前工作区，确认对应商品目录及其中的「轮播图」「详情图」。封面若与轮播首图相同，只视为同一张来源图。优先复用已有抓取结果。
2. 用户说「先抓后选」时，先按用户指定的抓品 Skill 和链接落盘。本工作区默认复用 [商品页采集](../product-page-capture/SKILL.md)。沿用用户指定的父目录。未指定时按工作区 [AGENTS.md](../../AGENTS.md) 的「先抓后选」规则存放。确认轮播和详情媒体已经保存、能打开且对应目标商品，再开始选图。抓取和选图共用该商品目录。
3. 商品身份或抓取来源仍无法从现有信息确定时，才询问缺少的资料。商品明确、只是比例不齐时，直接选图并补齐。

## 2. 盘点、筛选和初始缺口

1. 在商品目录里创建「商品名字＋选图」，例如「勺子选图」「车载吸尘器选图」。有用户指定的简称就用指定简称。已有对应选图目录时先核对其中的成品和说明，保留可用结果，按实际缺口接着做。
2. 批量读取「轮播图」和原始「详情图」里的图片文件，记录相对路径、真实格式、显示宽高和动静态。读取实际像素尺寸，遇到 EXIF 旋转时按旋转后的方向计算。目标为 `a:b` 时，用 `宽 × b == 高 × a` 判定。比如 720 × 1280 是 9:16，750 × 562 略偏离 4:3，应留作扩图候选。常用补图尺寸只供生成参考，符合比例的原图保留原尺寸。
3. 用缩略图总览逐组比较，需要看清小字或动图内容时再查看原图或多个代表帧。先排除损坏文件、视频、详情分隔条、纯装饰图和实质重复画面。比例内优先选择主体清楚、边缘完整、文字易读的图片，尽量涵盖全貌、使用场景、细节或配件。两张仅机身配色不同时，结合其余候选和用户关心的卖点判断是否值得同时保留。
4. 优先选可长期复用的素材。若选中带原有价格、限时促销或时效文字的原图，在说明里注明。轮播图和详情图都可选，画面质量与信息互补性优先于来源顺序。
5. 把入选图片原样复制到选图目录，用比例加序号命名，如 `1x1_01.jpg`。保持原文件格式与内容。符合比例且内容合适的 GIF 或动态 WebP 可以直接入选，保留完整动画。例如 720 × 1280 的功能演示 GIF 可以直接填一个 9:16 名额。
6. 创建 `选图缺口说明.md`，按比例记下目标张数、已选原图数、原始缺口，并列出入选图的来源与尺寸。每种比例分别扣减，某一比例的富余张数不能抵扣另一比例的缺口。

## 3. 用原图补齐缺口

1. **先按缺口规划。** 每个缺图名额选一张背景便于延展、内容适合该版式的参考原图。方图改横幅优先左右补背景，方图改竖幅优先上下补背景。源图边缘已有被裁切的商品或手部时，可只向安全的一侧延展，或者换一张主体更完整的参考图。跨比例可复用同一原图，各图仍应有明确用途。
2. **基于原图做 AI 外扩。** 使用未加边的商品原图作为编辑输入。按目标比例决定扩展方向，保持商品、人物、配件、文案和图标的比例及位置关系。让图像模型顺着边界生成同一场景的新增画面，接续地面、墙面、枝叶等可见结构，匹配透视、光向、阴影、反射、纹理和景深。工具支持遮罩时，保护原画面，只开放新增区域及必要的接缝。
3. **禁止用填充冒充扩图。** 不允许用纯色或同色色块、渐变色带、边框、底板、镜像、边缘像素拉伸、重复纹理或模糊原图填满画布。棚拍图也要延展原有的布光和接触阴影。文字密集的海报应保护原字和图标。多图教程可以逐幅延展照片里的实际场景，将原文排回新画幅。若构图无法自然延展，换一张合适的来源图。若工具重绘了商品或文字，使用原图内容修复并检查衔接，或重新生成。
4. **逐张验收再入目录。** 对照扩图前后的边缘，在成品尺寸检查线条是否连续、纹理和光影是否自然、原图矩形边界是否可辨认，并核对商品结构、数量、文案及实际宽高。若有色块、接缝、失真或错字，重新生成或换源图。比例有微差时，只裁新增的外围背景或等比缩放，保护商品和文字。扩图可用 `16x9_01-ai.png` 等名称，与原图共用该比例的序号。
5. **按合格成品计数。** 生图工具不可用或结果未通过验收时，继续完成原图筛选，在缺口说明中写明剩余张数和原因。

扩图提示词模板：

> 以提供的商品原图为编辑输入，向〔扩展方向〕做 AI 外扩，输出〔目标宽高比和尺寸〕。保留原图主体、人物、配件、文案和图标的完整性、比例与位置关系。让〔原图边缘的具体场景元素〕沿原有透视、纹理、光向、阴影与景深自然延伸到新画幅边缘，形成同一张连贯的画面。禁止纯色或同色色块、渐变色带、边框、底板、镜像、边缘拉伸、重复纹理和模糊填充。接缝处不得出现原图矩形轮廓，不得重画商品或改写文字。

## 4. 验收与交付

从选图文件夹重新读取实际成品，逐比清点。确认文件可打开、宽高精确、原图副本与来源一致，入选动图仍有多帧。扩图逐张对照来源看商品、配件、文字和接缝，重复或未通过的候选留在交付目录之外。临时预览和草稿也放在目录之外。

更新 `选图缺口说明.md`，保留首次统计并填入实测结果。表格使用以下列，原始缺口为首次选完原图后的差值，剩余缺口按最终合格成品计算。

| 宽高比 | 需要 | 原图已选 | 原始缺口 | 本次补齐 | 剩余缺口 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 16:9 | 3 | 0 | 3 | 3 | 0 |

逐图记录文件链接、像素尺寸、原素材相对路径，以及原图、背景扩展或参考图生成的方式。动图和含时效文字的图片可在对应条目注明。复跑时，沿用可核对的初始缺口与来源记录，将「本次补齐」改为「累计补齐」，按实际保留的补图更新完成情况。

最后提供选图文件夹和说明链接，简述原图数、补图数、实际剩余缺口。若本次先抓品，再提供商品目录链接。
